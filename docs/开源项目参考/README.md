# 开源项目参考

记录外部开源项目的客观信息，用于与本项目做能力对照、判断功能取舍与借鉴方向。

本目录**不属于本项目的模块文档**，不参与 [项目结构文档](../项目结构文档.md) 的模块索引，也不描述本项目自身的实现。本项目各业务模块的现状与边界以 `docs/modules/` 为准。

## 记录约定

- 一个项目一个文件，文件名用仓库名小写连字符命名（如 `stirling-pdf.md`），本页只做索引与约定，不堆项目内容。
- 只记客观事实、与本项目的对照结论、可借鉴方向与代价；不抄官方文档正文、不写使用教程、不复述对方架构细节。
- 数值型信息（Star、Fork、版本号、Issue 数）一律标注核实日期，只作快照，不作为长期事实引用。
- 每个项目的对照结论必须写明依据来源，无法从公开资料确认的内容明确标注「未核实」，不推测。
- 记录项目间差异时以「本项目当前实现」为基准，本项目实现变化后需回看对照结论是否仍成立。
