# 前端规范

> 前端开发规范由 skill `vue-ts-spec`（TypeScript 项目）或 `vue-spec`（JavaScript 项目）承载，通过 skill 按需加载对应模块的规范文件，避免全量读取。规范原文随 skill 分发，不依赖具体机器、操作系统或项目目录，可随 skill 在任意环境中使用。

## 使用方式

前端开发任务会自动触发对应 skill，skill 会根据任务类型按需加载对应的 reference 文件。

## 全局速查（通用规则）

1. Composition API：使用 `<script setup>`，不用 Options API
2. 路由懒加载：`() => import()` 动态导入
3. Props：TypeScript 项目用类型声明 `defineProps<Props>()`（Vue 3.5+ 可用响应式解构定义默认值，低版本用 `withDefaults()`）
4. Emits：显式声明事件；脚本内事件名用 camelCase，模板监听用 kebab-case；`update:modelValue` 等 v-model 协议保持 Vue 约定
5. 语义化标签：header/nav/main/section/footer，一个页面一个 `main`；不设机械层级上限，嵌套影响理解或复用时拆分
6. 完整异步状态：覆盖加载、空、错误、重试、取消、重复提交和旧响应覆盖，区分首次加载/后台刷新/提交/局部更新
7. 统一请求入口：不自行创建 Axios 实例；错误在请求层规范化为 `AppError`，保留状态码与后端详情
8. 动态 Tailwind 类名：用完整静态映射，禁止 `bg-${color}` 拼接
9. 可访问性：优先原生语义元素、键盘可操作、具备可访问名称，管理焦点与状态播报
10. 性能按证据优化：先测量，再使用虚拟列表、`shallowRef`、`v-memo` 或分包
11. 验证后交付：运行仓库已有的格式化、类型检查、Lint、测试和构建命令，如实报告结果

## 默认项目画像（仅在仓库事实未否定时采用）

以下为 skill 的默认项目画像，非所有项目的通用真理；仓库事实与画像冲突时以仓库事实为准：

1. 禁止 Element Plus，优先复用项目自定义组件
2. 图标统一 FontAwesome 6，不混用其他图标库或散落内联 SVG
3. 样式以 Tailwind 为主：原子类 > `@apply`（仅稳定局部组合）> 自定义 CSS
4. API 边界使用 snake_case，响应结构为 `{code, message, data}`，`code === 0` 为业务成功

## 约定优先级

发生冲突时按以下顺序处理：

1. 用户本次明确要求
2. 仓库级指令与项目文档（如项目 CLAUDE.md）
3. `package.json`、构建配置、类型配置、Lint 配置和真实接口契约
4. 同模块已有实现与共享组件
5. skill 推荐规则
