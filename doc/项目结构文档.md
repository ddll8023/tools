# 工具盒子 项目结构导航文档

项目根目录：当前 Git 仓库根目录（`ROOT`）

> 本文档用于按问题类型快速定位当前代码文件；文件功能以当前仓库实现为准。

## 路径与跨设备约定

本文档正文统一使用仓库相对路径，`ROOT` 表示当前 Git 仓库根目录，不绑定任何设备的盘符或用户目录。当前已知开发位置如下：

| 设备环境 | 本机项目根目录 | 使用说明 |
|---|---|---|
| macOS（当前工作区） | `/Users/mima1234/Desktop/code/tools` | AI 可直接从当前仓库根目录按相对路径读取 |
| Windows（另一开发设备） | `H:/code/tools` | 切换到该设备后继续使用相同仓库相对路径 |

**AI 读取规则**：

1. 先确认当前工作目录位于 `ROOT`；正文中的 `frontend/...`、`backend/...` 等路径均相对于 `ROOT`。
2. 优先使用仓库相对路径，不能把另一台设备的绝对路径当作当前路径。
3. 工具必须使用绝对路径时，可通过只读命令 `git rev-parse --show-toplevel` 获取当前设备的 `ROOT`，再拼接文档中的相对路径。
4. 两台设备只需保持 Git 仓库结构和分支同步；设备目录变化时只更新本节映射，不修改正文文件路径。
