# 工具盒子 项目结构文档

## 技术栈

| 类别 | 技术 | 说明 |
|---|---|---|---|
| 前端框架 | Vue 3 (^3.5.13) | Composition API + `<script setup>` |
| 构建工具 | Vite (^6.3.0) | 开发服务器与打包构建 |
| CSS 框架 | Tailwind CSS v4 (^4.1.4) | 原子化 CSS，通过 `@tailwindcss/vite` 插件集成 |
| 状态管理 | Pinia (^3.0.2) | 全局 UI 状态（侧边栏收起/展开） |
| 路由 | Vue Router (^4.5.0) | hash 模式，配置化工具路由注册 |
| 图标 | FontAwesome 6 | 通过 `@fortawesome/vue-fontawesome` 组件使用 |
| 测试 | Playwright + Chromium | E2E 测试，`frontend/tests/` |
| 代码规范 | TypeScript + Prettier | 类型检查 + 类名排序插件 |
| 桌面壳 | Electron (^31) | 主进程管理后端+Vite 子进程，创建 BrowserWindow |
| 后端框架 | FastAPI (0.138) + Python 3.12 | RESTful API，统一响应格式，全局异常处理 |
| 后端工具 | uv (0.10) | Python 包管理与虚拟环境 |
| 后端服务 | Uvicorn (0.49) | ASGI 服务器，开发模式带 `--reload` |
| 后端文档解析 | PyMuPDF (1.27) + MinerU (3.4.0) | 标准模式快速解析 + 深度模式 AI 文档解析 |
| 后端文档转换引擎 | LibreOffice (26.2) | Word 转 PDF，便携版部署在项目中 |
| 后端图片处理 | Pillow (12.2) | 图片格式转换（PNG/JPEG/WebP/BMP/GIF/TIFF），色彩模式归一化 |

## 项目结构

```
tools/
├── package.json                        # Electron 依赖 + 构建脚本
├── .gitignore                          # 忽略 node_modules/ __pycache__/ .venv/ resources/
├── start-dev.bat                       # Windows 开发启动脚本（后端 → Vite）
├── CLAUDE.md                           # 项目指南（测试方法 + 后端启动）
├── 规范文档/
│   ├── 前端规范文档.md                  # 前端编码规范索引
│   └── 后端规范文档.md                  # 后端编码规范索引
├── doc/
│   ├── 项目结构文档.md                  # 本文档
│   └── 模块说明文档.md                  # 业务功能模块设计说明
├── prototype/
│   ├── index.html                      # 首页设计原型
│   ├── pdf-to-markdown.html            # 工具页设计原型
│   └── design-doc.md                   # 前端设计说明文档
├── electron/
│   ├── tsconfig.json                   # TypeScript 编译配置（CJS）
│   ├── main.ts → main.js               # 主进程：窗口 + Vite + 后端进程管理
│   ├── preload.ts → preload.js         # 预加载脚本（contextBridge）
│   └── dev-runner.js                   # 开发启动器（后端 → Vite → Electron）
├── frontend/
│   ├── package.json                    # 前端依赖（Vue/Router/Pinia/Tailwind/...）
│   ├── vite.config.ts                  # Vite 配置（base: './' + 固定端口）
│   ├── playwright.config.ts            # Playwright 配置
│   ├── playwright-electron.config.ts   # Electron Playwright 配置
│   ├── tsconfig.json / tsconfig.*.json # TypeScript 配置
│   ├── index.html / env.d.ts           # 入口
│   └── src/
│       ├── main.ts                     # 应用入口
│       ├── App.vue / style.css         # 根组件 + 样式
│       ├── router/ (index.ts, tools.ts)# 路由 + 工具配置
│       ├── stores/layout.ts            # 侧边栏状态
│       ├── types/tool.ts               # ToolConfig + ApiResponse
│       ├── api/tools.ts                # 工具 API 调用（PDF-MD + Word-PDF + 图片转换的 convert/download）
│       ├── components/layout/          # AppShell + AppSidebar（支持不可用工具灰化）
│       └── views/ (home/ tools/ error/)# 页面（ImageConverter.vue 新增）
├── backend/
│   ├── resources/                      # 统一外部依赖目录
│   │   ├── LibreOfficePortable/        # LibreOffice 便携版（Word 转 PDF 引擎）
│   │   └── mineru/                     # MinerU 深度学习模型缓存目录
│   ├── pyproject.toml                  # Python 依赖（FastAPI/Uvicorn/Pydantic）
│   ├── uv.lock                         # 依赖锁定
│   ├── .env                            # 环境变量（DATABASE_URL/API_PORT + MINERU_MODEL_PATH）
│   ├── .python-version                 # Python 3.12
│   └── app/
│       ├── main.py                     # FastAPI 入口（路由注册 + 全局异常处理器 + 启动检测 LibreOffice）
│       ├── core/config.py              # Settings 单例（BaseSettings + 自动检测 libreoffice_path）
│       ├── utils/
│       │   ├── exception.py            # ServiceException
│       │   ├── file.py                 # save_file 工具
│       │   ├── logger_config.py        # setup_logger + ProgressLogHandler
│       │   └── temp_cleanup.py         # 临时文件清理（TEMP_DIR、get_task_dir、cleanup_expired_temp）
│       ├── schemas/response.py         # success/error + ApiResponse + ErrorCode（含 3 个新错误码）
│       ├── schemas/tools/
│       │   ├── pdf_to_markdown.py       # PDF-MD 转换请求/响应 Schema + 进度查询
│       │   ├── word_to_pdf.py           # Word-PDF 转换请求/响应 Schema
│       │   ├── image_converter.py       # 图片转换 Schema（格式枚举/响应/下载请求）
│       │   └── list.py                  # 工具列表条目（含 available 字段）
│       ├── services/tools/
│       │   ├── pdf_to_markdown_helpers.py # PDF-MD 共享辅助函数（预览、下载、输出归一化）
│       │   ├── pdf_to_markdown.py       # PyMuPDF 标准转换服务
│       │   ├── pdf_to_markdown_deep.py  # MinerU 深度转换服务（异步 + ProcessPoolExecutor）
│       │   ├── word_to_pdf.py           # Word 转 PDF 服务（LibreOffice CLI 同步转换）
│       │   ├── image_converter.py       # 图片格式转换服务（Pillow 核心逻辑 + ZIP 打包）
│       │   └── list.py                  # 工具列表获取服务（动态可用性注入）
│       └── api/v1/
│           ├── health.py               # POST /api/v1/health
│           └── tools/
│               ├── list.py             # POST /api/v1/tools/list
│               ├── pdf_to_markdown.py  # 4 个接口：convert(标准/深度)/progress/preview/download
│               ├── word_to_pdf.py      # 2 个接口：convert/download
│               └── image_converter.py  # 3 个接口：convert/download/download-all
```

### 依赖配置文件

| 文件 | 说明 |
|---|---|
| `package.json`（根） | Electron + electron-builder + TypeScript 依赖 |
| `frontend/package.json` | 前端依赖（Vue 3 / Router / Pinia / Tailwind v4 / FontAwesome / Playwright） |
| `backend/pyproject.toml` | 后端依赖（FastAPI / Uvicorn / pydantic-settings / pymupdf / python-multipart / mineru / python-docx） |
