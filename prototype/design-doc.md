# 工具盒子 - 前端设计说明

## 一、模块概述

- **所属产品**：工具盒子（Tool Box）
- **目标用户**：办公 / 技术用户，需要快速完成文档格式转换和文本处理
- **核心功能**：以插件化方式提供多个文档处理工具，首期实现 PDF 转 Markdown
- **设计风格**：浅色明亮，浅黄色品牌色，圆角卡片化，全局顶部栏 + 可收起侧边栏

## 二、页面清单

### 页面 1：首页 - 工具网格

- **原型文件**：`prototype/index.html`
- **功能描述**：以网格卡片形式展示所有可用工具，是用户进入产品后的第一站
- **主要元素**：
  - 顶部栏：左侧汉堡菜单 + 产品名，右侧搜索框（预留）
  - 侧边栏：默认隐藏，点击汉堡菜单展开，列出所有工具导航
  - 内容区：Logo + 产品标题 + 工具卡片网格（3 列自适应）
- **交互说明**：
  - 点击汉堡菜单：侧边栏以动画滑入/滑出
  - 侧边栏展开后，点击首页或任意工具项进行页面切换
  - 鼠标悬停卡片：整体上移 3px，阴影加深
  - 不可用卡片（即将上线）：降低透明度，无悬停效果
- **设计要点**：
  - 首页默认侧边栏收起，让用户聚焦于工具网格的全屏浏览体验
  - 侧边栏完全隐藏而非图标模式，内容区获得最大展示宽度

### 页面 2：PDF 转 Markdown 工具页

- **原型文件**：`prototype/pdf-to-markdown.html`
- **功能描述**：在一个页面内完成上传 → 转换 → 预览下载的全流程
- **主要元素**：
  - 顶部栏：左侧汉堡菜单 + 产品名，中央当前工具名，右侧搜索框
  - 侧边栏：默认展开，当前工具高亮显示，可随时切换工具或返回首页
  - 上传区：虚线拖拽框 + 选择文件按钮
  - 转换进度：进度条 + 分步状态指示器
  - 结果区：操作按钮行 + 统计信息 + Markdown 语法高亮预览
  - 错误提示：红底错误卡片
- **交互说明**：
  - 侧边栏展开状态下，当前工具「PDF 转 Markdown」行高亮（黄底深黄字）
  - 点击侧边栏其他项（如首页）跳转对应页面
  - 即将上线的工具项降低透明度，点击无反应
  - 工具页内四种状态通过顶部演示按钮切换查看
- **设计要点**：
  - 工具页侧边栏默认展开，方便在多工具间切换，符合"工具盒子"的产品定位
  - 顶部栏中央显示当前工具名，用户在侧边栏收起时也能明确当前位置

## 三、页面跳转关系

```
首页（工具网格）
  │
  ├── 点击「PDF 转 Markdown」卡片 ──→ PDF 转 Markdown 工具页
  │
  └── 侧边栏展开 → 点击「PDF 转 Markdown」 ──→ PDF 转 Markdown 工具页

PDF 转 Markdown 工具页
  │
  ├── 侧边栏 → 点击「首页」 ──→ 回到首页
  │
  └── 侧边栏 → 点击其他工具 ──→ 对应工具页（后续实现）
```

## 五、配色方案

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#F5A623` | 按钮、图标底、进度条、高亮、活动指示 |
| 主色浅 | `#FDEBD0` | 图标背景、悬停状态、侧边栏活跃项 |
| 主色深 | `#D4890A` | 按钮悬停 |
| 页面背景 | `#FAFAF8` | 整体底色 |
| 卡片/内容背景 | `#FFFFFF` | 内容区底色 |
| 主文字 | `#2D2D2D` | 标题与正文 |
| 辅助文字 | `#999999` | 描述说明、次要信息 |
| 边框 | `#EBEBE7` | 卡片、分割线、侧边栏边界 |
